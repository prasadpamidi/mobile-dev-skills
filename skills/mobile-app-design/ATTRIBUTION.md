# Attribution

This skill adapts selected design principles from Taste Skill by Leonxlnx:

- Begin with details specific to the subject instead of category defaults.
- Make deliberate visual decisions and avoid generic, repeated layouts.
- Review the rendered result and improve the most important issues.

The mobile workflow, examples, framework guidance, and references in this package are newly written
for native and cross-platform mobile app design. The upstream project is licensed under MIT; its full
